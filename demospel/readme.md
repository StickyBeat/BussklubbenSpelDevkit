Schoolbus Simulator
=====
Ett exempelspel för bussklubben som använder sig av Bussklubbens API.

Projektet använder sig av byggverktyget **Vite**. För att installera allt som behövs kör du 
```
npm install
```
För att starta utveckling kör du
```
npm run dev
```
För att bygga spelet för leverans kör du
```
npm run build
```
Spelet byggs i mappen `dist`

Om du vill ha en tom mall för att bygga ditt eget spel så finns det här [Template](../template/readme.md)
