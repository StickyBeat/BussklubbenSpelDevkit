Bussklubben Spel Template Javascript
=====
Gör en kopia av detta projekt och börja bygga ditt eget spel till Bussklubben!


Projektet använder sig av byggverktyget **Vite**. För att installera allt som behövs kör du 
```
npm install
```
För att starta utveckling kör du
```
npm run dev
```
För att bygga spelet för leverans kör du
```
npm run build
```
Spelet byggs i mappen `dist`

För tips om hur du bygger spelet och hur du kan använda Bussklubbens API kan du kolla på demospelet som finns här [Demospel](../demospel/readme.md)
